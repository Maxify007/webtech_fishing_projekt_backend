# ClickNFish 🐟🎣

ClickNFish is a small idle / clicker game built with **Vue 3** and **Vite**.

In the game, players create their own fisher and start catching fish by clicking.  
Caught fish can be used for currency, which is then used to buy upgrades such as:

- Better fishing rods  
- Faster fishing speed  
- Automatic fishing helpers  
- Increased fish value  

A Leaderboard gives Players the chance to compete and be the best Fisher!

The project is developed as part of the **HTW WebTech** module.
